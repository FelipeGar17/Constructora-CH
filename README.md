# Portafolio Finca Raíz V2

Sitio web de Constructora Hernandez para proyectos y propiedades en el área metropolitana de
Bucaramanga.

## Desarrollo

Consulta [`READMEDESARROLLO.md`](./READMEDESARROLLO.md) para la estructura del proyecto, comandos,
catálogo, despliegue y pendientes. La bitácora de cambios está en
[`Desarrollo.md`](./Desarrollo.md).

## Comandos

```bash
npm install
npm run dev
npm run build
npm run typecheck
npm run lint
```

## Despliegue actual

El proyecto se publica en Cloudflare Workers mediante OpenNext. La URL temporal actual es:

`https://constructora-ch.fevora.workers.dev`
